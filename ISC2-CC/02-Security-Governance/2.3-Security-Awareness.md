# 2.3 — Understand Security Awareness

[← Domain 2](./README.md)

## Awareness vs Training

| Training | Awareness |
|---|---|
| สอน skill | เปลี่ยน behavior/attention |
| “ทำอย่างไร” | “ระวังอะไร/ทำไม” |
| role-specific | organization-wide ได้ |
| hands-on | campaign/reminder/scenario |

Security awareness ไม่ใช่ annual video แล้วจบ เป้าหมายคือให้คนตัดสินใจปลอดภัยขึ้นในชีวิตจริง

## Security culture

culture ที่ดีเห็นได้จาก reporting ที่ง่าย, leadership ทำตาม policy, exception มี owner/เหตุผล และ lessons learned ถูกใช้ปรับระบบ

culture ที่ทำให้คนกลัวการรายงานจะซ่อน incident จนใหญ่ขึ้น

## Leadership

ผู้นำต้อง sponsor program, assign ownership, fund priorities และทำตาม policy เอง

ถ้าผู้บริหาร bypass MFA หรือ share password จะส่ง signal ว่า policy ไม่สำคัญ

## Social engineering

attacker ใช้ psychological levers เช่น authority, urgency, fear, curiosity, scarcity และ familiarity

## Phishing family

- phishing — mass
- spear phishing — targeted
- whaling — high-value target
- vishing — voice
- smishing — SMS/message

defense ใช้หลายชั้น: awareness + verification + MFA + filtering + reporting + least privilege

## Password protection

แนวคิดสำคัญคือ unique passwords, password manager, MFA, no sharing, recognizing credential phishing และ secure reset process

## AI-enhanced social engineering

AI ทำให้ phishing/impersonation personalize และ scale ได้เร็วขึ้น

หลัก defense ยังเหมือนเดิม: verify identity/request ผ่าน trusted channel, ลด privilege และ report anomalous requests

## Scenario

phishing simulation ของทีมหนึ่ง click สูง

response ที่ดีคือ targeted awareness + context review + reporting reinforcement + trend measurement ไม่ใช่ประจานทีม

## Knowledge check

1. Awareness ต่างจาก training อย่างไร?
2. security culture สังเกตจากพฤติกรรมอะไร?
3. spear phishing ต่างจาก phishing อย่างไร?
4. leadership behavior มีผลต่อ culture อย่างไร?
5. AI ทำให้ social engineering เปลี่ยนอย่างไร?
