# 5.2 — Understand Security Operations

[← Domain 5](./README.md)

## Logging and monitoring

log คือ evidence ของ activity; monitoring คือ process ที่ใช้ evidence เพื่อ detect/understand events

แหล่งข้อมูลอาจมาจาก:

- identity/authentication
- endpoints
- firewalls
- applications
- cloud control plane
- databases
- IDS/IPS
- DNS/proxy

## SIEM mental model

~~~text
many logs
→ normalize/collect
→ correlate
→ detect use case
→ alert
→ triage
~~~

SIEM ไม่ได้ทำให้ทุก log มี value โดยอัตโนมัติ ต้องมี use cases, quality และ context

## Security event triage

triage ตอบ:

1. เหตุการณ์จริงหรือ noise?
2. กระทบ asset ไหน?
3. severity/priority เท่าไร?
4. ต้อง escalate หรือไม่?
5. evidence อะไรต้อง preserve?

### Priority

priority ไม่ควรอิง “เสียง alert ดังแค่ไหน” อย่างเดียว

ควรรวม:

- asset criticality
- confidence
- scope
- impact
- active exploitation
- data sensitivity

## Correlation

หลาย event ที่ดูปกติแยกกันอาจมีความหมายเมื่อเชื่อมกัน

ตัวอย่าง:

~~~text
failed logins
+ successful login from new region
+ privilege change
+ data download
→ higher-confidence incident
~~~

## Threat actors

คิดจาก capability + intent + motivation

ตัวอย่าง categories:

- cybercriminal
- nation-state
- insider
- hacktivist
- competitor
- opportunistic attacker

motivation อาจเป็น money, espionage, disruption, ideology, revenge หรือ curiosity

## Cyber Threat Intelligence (CTI)

CTI คือ analyzed threat information ที่ช่วย decision

ไม่ใช่ raw indicator list อย่างเดียว

อาจช่วย:

- prioritize vulnerabilities
- understand actor behavior
- create detections
- prepare defenses

## Threat frameworks

framework ช่วยให้ทีมใช้ภาษาร่วมกันอธิบาย adversary behavior

ระดับ CC ให้เข้าใจ purpose มากกว่าท่องทุก technique

## AI-assisted operations

AI อาจช่วย correlation, anomaly detection, summarization และ prioritization

risk:

- false positive/negative
- automation bias
- missing context
- poisoned/bad data

human validation ยังสำคัญโดยเฉพาะ high-impact response

## Scenario

SIEM สร้าง alert 500 รายการ แต่มีเพียง 3 รายการเกี่ยวกับ privileged account บน critical server

triage ต้อง prioritize ตาม business/security context ไม่ใช่ first-come-first-served

4. CTI ต่างจาก raw indicator อย่างไร?
