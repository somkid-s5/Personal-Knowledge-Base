## Data handling

security ของข้อมูลเริ่มจากรู้ว่าข้อมูลมี sensitivity แค่ไหนและต้องปฏิบัติกับมันอย่างไร

### Classification

กำหนด category ตาม sensitivity/impact เช่น Public, Internal, Confidential, Restricted

classification ควร drive controls

### Labeling

ทำให้ classification ถูกผูก/มองเห็นได้ เช่น metadata, document label หรือ header

label ที่ไม่มี enforcement เป็นเพียงข้อความ

### Masking

ซ่อนค่าจริงบางส่วนเพื่อใช้ใน lower-trust context เช่นแสดงเลขบัตรเพียง 4 ตัวท้าย

### Sanitization

ทำให้ข้อมูลบน media ไม่สามารถถูกกู้กลับได้ตามระดับ assurance ที่ต้องการ

delete หรือ format อย่างเดียวอาจไม่เพียงพอ

## Data states

- **At rest** — stored
- **In transit/motion** — moving across network
- **In use** — being processed

control ต้องเหมาะกับ state

## Symmetric encryption

ใช้ secret key เดียวสำหรับ encrypt/decrypt

ข้อดี: เร็ว เหมาะกับ bulk data

ความท้าทาย: key distribution/protection

## Asymmetric encryption

ใช้ public/private key pair

ข้อดี: key exchange, signatures, scalable trust patterns

ข้อเสีย: computationally heavier

## Hashing

one-way function สร้าง fixed-length digest ใช้ช่วยตรวจ integrity

hash ไม่ใช่ encryption เพราะไม่มี decryption กลับ plaintext

## Hybrid cryptography

ระบบจริงมักใช้ asymmetric เพื่อ establish/share session secret แล้วใช้ symmetric สำหรับ data transfer

## Quantum-resistant cryptography

current outline เพิ่ม quantum-resistant cryptography ในระดับ concept

mental model:

> ออกแบบ cryptographic algorithms ให้ต้านการโจมตีจาก quantum-capable adversaries ในอนาคต

ไม่ต้องตีความว่า “quantum encryption” คือสิ่งเดียวกัน

## AI workspace data leakage

ห้าม assume ว่า public AI service เป็น private data sink

ก่อนส่ง prompt/file ควรรู้ classification, retention, training-use, contractual control และ approval

masking/sanitization อาจลด exposure เมื่อ use case อนุญาต

## Common traps

| Trap | Correct mental model |
|---|---|
| Hash = encryption | hash is one-way integrity primitive |
| Delete = sanitize | deletion may leave recoverable data |
| Label = protection | label must drive controls |
| SaaS/AI vendor secure = data sharing safe | customer data-handling responsibility remains |
