## Purpose

Incident Response ทำให้การตอบ security incident เป็น process ที่ predictable และ authorized แทนการ improvisation ตอนกดดัน

## Incident Response Plan (IRP)

IRP ควรทำให้ทีมรู้:

- ใครมี role อะไร
- escalation path
- communication path
- evidence handling
- decision authority
- containment/recovery expectations
- external/legal contacts เมื่อจำเป็น

## Data handling policy in IR

incident อาจมี logs, malware samples, screenshots, memory images, user data และ evidence อื่น

ต้องรู้:

- ใครเข้าถึงได้
- เก็บที่ไหน
- label/classification อะไร
- preserve integrity อย่างไร
- retention เท่าไร

## Response mental model

แม้ frameworks จะใช้ชื่อ phase ต่างกัน ให้จำ flow:

~~~text
Prepare
→ Detect/Identify
→ Triage/Analyze
→ Contain
→ Eradicate
→ Recover
→ Learn/Improve
~~~

อย่ากระโดดไป “ลบ malware” ก่อน preserve evidence/understand scope หากสถานการณ์ต้อง investigation

## Communication

incident communication ต้องกำหนดล่วงหน้า

ผิด:

> ใครก็ได้โพสต์รายละเอียด incident

ดีกว่า:

- designated communicator
- need-to-know
- legal/privacy review
- approved channel

## Exercises

### Tabletop

เดิน scenario ด้วย discussion

เหมาะกับ role, decision, communication, dependency

### Simulation / technical exercise

ทดสอบ capability จริงมากขึ้น

### Testing purpose

หาช่องว่างก่อน incident จริง ไม่ใช่ทำเพื่อ “ผ่าน audit” อย่างเดียว

## AI-related incident response

AI system incident อาจรวม data leakage, prompt abuse, model/data poisoning, unauthorized agent action หรือ provider compromise

entry-level practitioner ควร follow playbook, preserve evidence และ escalate ไม่ improvise high-impact action

## Scenario

EDR แจ้ง malware บนเครื่อง critical แต่ analyst รีบ reimage ทันทีโดยไม่ collect evidence

อาจลด immediate threat แต่ทำลาย evidence และ scope understanding

correct response ขึ้นกับ IRP และ severity แต่ต้อง follow authorized process

## Knowledge check

1. IRP ทำให้ response ดีขึ้นอย่างไร?
2. data handling policy สำคัญต่อ evidence อย่างไร?
3. containment ต่างจาก eradication อย่างไร?
4. tabletop test อะไรได้ดี?
5. ทำไม lessons learned สำคัญ?
