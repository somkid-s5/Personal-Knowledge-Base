# Quality Gate

Run this before marking a package `Verified`, `Complete`, or `100%` within a declared scope.

## A. Scope and navigation
- [ ] Package README states learner, goal, scope and exclusions.
- [ ] Source of truth and last verified date are recorded where relevant.
- [ ] Root/provider/package navigation links are updated.
- [ ] Learning order is obvious.

## B. Coverage
- [ ] Official syllabus/objective inventory exists for certification/course-complete claims.
- [ ] Every objective maps to real explanatory content.
- [ ] No objective is represented only by a heading/name.
- [ ] Known lab/practice exclusions are explicit.

## C. Understanding
- [ ] Major concepts explain purpose and mental model.
- [ ] Similar services include decision criteria/tradeoffs.
- [ ] Common misconceptions are addressed where meaningful.
- [ ] Important operational topics include verification and failure/troubleshooting guidance.

## D. Visuals
- [ ] Hierarchies/flows/architecture/decision-heavy concepts have useful visuals.
- [ ] Diagrams are readable and explained by surrounding text.
- [ ] Screenshots are used only when UI location matters.

- [ ] Icon/emoji memory cues match the subject and are paired with searchable technical labels.
- [ ] SVG visual guides and diagrams render without remote dependencies and have meaningful alt text.
- [ ] Official vendor logos, if present, have provenance and rights guidance; original pictograms are not mislabeled.

## E. Accuracy and safety
- [ ] High-impact claims use current official sources.
- [ ] Volatile facts are dated or linked rather than frozen as timeless truth.
- [ ] Commands identify destructive/cost/security implications when relevant.
- [ ] No credentials, tokens or production secrets exist in the content.
- [ ] No exam dumps or proprietary grader solutions are included.

## F. Review experience
- [ ] Major modules have summaries/questions/scenarios.
- [ ] Cheat sheet does not substitute for detailed teaching notes.
- [ ] Terminology is searchable against official docs.
- [ ] Markdown tables, links and Mermaid blocks are structurally valid by inspection/tooling available.

## Completion labels
- `Verified` = all applicable checks pass for the declared scope/date. A substantial Verified learning system or nested verified layer must expose source traceability (`SOURCE-MANIFEST.md`) and QA evidence so the claim is independently reviewable.
- `100% coverage` = every item in an explicit official inventory passes; this does not mean mastery of the entire technology or guaranteed exam success.
