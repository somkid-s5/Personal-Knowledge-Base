# Content Templates

These templates implement the repository standards in `AGENTS.md`, `SKILL.md`, `skills/` and `docs/`.

Use them as scaffolds; remove sections that genuinely do not apply, but do not omit scope/source/status information from substantial packages.

- `LEARNING-PACKAGE-README.md` — package landing page
- `SOURCE-MANIFEST.md` — source inventory, authority, provenance and verification record
- `SOURCE-COVERAGE.md` — source-ingestion fidelity/coverage matrix
- `MODULE.md` — detailed theory/operations module
- `LAB.md` — original companion lab
