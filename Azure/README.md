## Structure for future Azure content

Use `Courses/`, `Certifications/`, `Topics/` or `Projects/` according to [`docs/REPOSITORY-ARCHITECTURE.md`](../docs/REPOSITORY-ARCHITECTURE.md).

Azure certification packages must record the Microsoft Learn skills-measured date because Microsoft updates role-based exams periodically.
