## ⚖️ ทำไมไม่รวม Lab/Project เข้ากับ Module?

- Module: อธิบายแนวคิด/การเลือกบริการ/Architecture Tradeoffs
- Lab: ขั้นตอนฝึกใช้ AWS และตรวจผลตามสภาพแวดล้อมที่ได้รับอนุญาต
- Project: โจทย์ออกแบบ/สร้างระบบเพื่อฝึกงานจริงและทำ Portfolio
- Scenario: ฝึกตัดสินใจตามโจทย์สอบ — **ไม่เท่ากับ Deploy จริง**

> ตารางนี้เป็นแผนการอ่าน; ไม่ใช่หลักฐานว่า AWS Labs/Projects ได้ Execute ผ่านแล้ว และไม่มีการเปลี่ยน Lesson IDs หรือย้ายไฟล์จาก Repo
