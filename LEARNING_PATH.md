# Recommended Learning Path

This guide outlines the optimal sequence to tackle these 34 projects.

## Stage 1: The Foundation (Beginner)
**Projects:** 01 - 05
**Goal:** Master the basic building blocks of the cloud.
**Outcome:** You can deploy a static website, harden a server, containerize an app, and set up basic monitoring.

## Stage 2: The Infrastructure Architect (Junior)
**Projects:** 06 - 11
**Goal:** Learn to build production-grade environments using Infrastructure as Code (Terraform), CI/CD pipelines, and cost optimization.
**Outcome:** You understand VPCs, ALB, ASG, RDS, how to automate deployments via GitHub Actions, and how to manage costs.

## Stage 3: The Kubernetes Master (Mid-Level)
**Projects:** 12 - 18
**Goal:** Dive deep into the Kubernetes ecosystem.
**Outcome:** You can manage EKS clusters, implement Service Mesh (Istio), centralize logging, and manage secrets at scale.

## Stage 4: The Platform Engineer (Senior)
**Projects:** 19 - 25
**Goal:** Shift from managing infrastructure to building internal developer platforms.
**Outcome:** You can build developer portals (Backstage), handle multi-region disasters, and implement Zero-Trust.

## Stage 5: The Cloud Leader (Staff/Principal)
**Projects:** 26 - 30
**Goal:** Lead large-scale organizational initiatives.
**Outcome:** You can lead massive migrations, implement enterprise GitOps, and build full-scale Observability and SecOps platforms.

## Stage 6: The Architect (Capstone)
**Projects:** 31 - 34
**Goal:** Connect everything together with enterprise-grade networking, advanced observability, and Well-Architected Reviews.
**Outcome:** You can design and review full end-to-end cloud architectures, manage hybrid connectivity (BGP, VPN), and perform comprehensive Well-Architected assessments across all 6 pillars.

---

## When are you ready for a job?
- **Junior Cloud Engineer:** After completing Projects 01-11.
- **Cloud Engineer:** After completing Projects 01-18.
- **Senior Cloud Engineer:** After completing Projects 01-25.
- **Staff/Principal Engineer:** After completing Projects 01-30.
- **Cloud Architect:** After completing all 34 projects.
