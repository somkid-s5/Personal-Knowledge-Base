The exact tool depends on the problem.

- logical export/import,
- bulk loading,
- external tables,
- transportable approaches,
- cross-database movement.

Current command behavior should be checked against the 26ai Utilities Guide.

## Maintenance

Automated maintenance is useful only when windows are understood, resource impact is controlled, jobs are monitored, failures are visible and business workload is considered.
