# Learning Content Authoring Skills

This directory contains the two supported content-building modes for this knowledge base.

| Mode | Skill | Use when |
|---|---|---|
| Internet-first | [INTERNET-FIRST-CURRICULUM.md](./INTERNET-FIRST-CURRICULUM.md) | No complete source course is provided; build the learning package from current official Internet sources. |
| Source-ingestion | [SOURCE-INGESTION-CURRICULUM.md](./SOURCE-INGESTION-CURRICULUM.md) | The user provides PDFs, slides, documents, images, course exports or another source set that should be understood and converted into the repository format. |

`../SKILL.md` is the router. Agents must select one primary mode before substantial authoring begins.

## Hybrid work

If the user provides a course **and** asks for current updates, use **Source-ingestion as the primary mode** and Internet-first research only as an explicitly labeled supplement/current-verification layer.

Never silently replace the supplied course with Internet material, and never treat an old course as current merely because it is the supplied source.
